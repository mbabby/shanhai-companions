## v0.3 历史交付

按用户授权方案完成六兽统一手绘、战术优化、轻量成长、本地存档和可选声音。美术新增狸力、狌狌、鯥，全部采用已确认的东方幻想绘本方向；仍为静态立绘配合 CSS 动作。

- 护盾先于普通攻击；敌方会根据公开状态防守或换兽，并有换位间隔避免循环。六兽定位与可复现前后对照见 [平衡记录](balance-v0.3.md)。同一水初始队伍，直接攻击失败、按克制换位胜利；无需先刷经验。
- 经验 0–90、等级 1–3；胜利 +30、失败/平局 +10；每级生命 +8、攻击 +2、防御 +1。初始三兽 3 级特色技能威力 +4，下一场生效，结算仅领取一次。
- 阶段和完整回合自动保存；继续旅程、JSON 导入导出、原文导出、滚动备份恢复、确认新旅程。损坏/未来版本不被普通自动保存覆盖；演出中刷新回到该回合开始前。
- 音效与背景氛围分别开关，默认关闭、交互后解锁，无外部采样。行动者高亮，生命/护盾/回复分色，手机重要数值与技能说明保持可读尺寸。

## v0.2 已确认美术接入

用户确认三兽设计稿与对战界面风格后，接入九尾狐、旋龟、鹿蜀手绘 PNG 及溪石背景；其余三兽保留 SVG 原型。参考稿和生成提示词保存在 `docs/art-direction/`，实际素材在 `assets/`。

战斗新增顺序事件与只读快照，界面按真实事件播放出招、元素飞弹、受击、护盾、回复、倒下和补位。回合演出锁定行动，可切换倍速与减少动态效果。生命、护盾、全队生命、攻防速度和状态剩余时长均由实际规则驱动，技能预估标明当前面板条件。

`npm test` 25 项通过（15 项规则回归 + 10 项事件与预估）；静态构建包含所有 PNG。

独立浏览器 QA 验收：

- 1440×1000 与 390×844，三种初始伙伴共六条完整流程；胜负、重试满血、错误结契恢复、调整领队、重开、刷新重置均通过，无页面/控制台错误或横向溢出。
- 出招与飞弹不同动画帧、先后手分次扣血、连点只结算一回合、护盾 28/28 实际吸收、血条宽度/全队生命/伤害预估与内核一致。
- 灼伤、减速剩余次数，手机减少动态效果，全场播放至结局通过。
- 三张角色 PNG 透明区域和主体不透明度通过检查，无矩形背景；主代理复查桌面和手机截图。
- 修复 SVG 角色朝向，压缩桌面战场，使三张技能卡在 1000px 高视口内完整可见。

测试脚本为 `npm run test:browser` 与 `npm run test:presentation`，依赖可选 Playwright；手机仍为视口模拟，不等同真机测试。

本轮不调整战斗平衡数值，不加入效果图示例等级；使用立绘配合 CSS 演出，并非逐帧或骨骼动画。旧版关于存档、升级、进化和音效的限制继续成立。

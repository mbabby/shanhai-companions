# 第一章浏览器验收

日期：2026-11-18。独立 QA，Chrome + Playwright，桌面 1440×1000 与手机模拟 390×844。

## 可复现命令

保持 `npm run dev` 运行，安装可选 Playwright 或通过环境变量复用本机安装：

```sh
PLAYWRIGHT_MODULE_PATH=/path/to/playwright/index.mjs \
CHROME_PATH='/Applications/Google Chrome.app/Contents/MacOS/Google Chrome' \
node tests/browser-chapter.mjs
```

`BASE_URL`、`SCREENSHOT_DIR` 可覆盖地址与截图位置。`QA_WIDTH`、`QA_STARTER` 仅用于定位问题，完整验收应省略。旧版 browser-smoke/presentation/save 脚本使用旧线性流程，不能作为第一章验收结果。

## 验收设计

六条首通路径全部从空浏览器状态出发，通过真实 UI 选择初始兽、走访八处、环境互动、两步习性结契、队伍调整、三场战斗和尾声。首次通关不注入剧情状态，不替换战斗结果。测试读取存档作为断言与合法战术选择依据；只有独立迁移/损坏存储测试写入特制旧档或无效原文。

覆盖三初始伙伴 × 两视口；六兽收集；错误回应不倒退；半途结契刷新；后备替换、移出/加入与领队；祠前训练后仍须分别确认三种进化；三场首胜与重访无重复经验/道具；完整回合保存、演出中刷新；导出导入、备份恢复与取消新旅程；v1 队伍/经验/设置迁移、原文保护；损坏及未来档导出、禁用存储；页面横向溢出、图片加载、控制台异常。战斗中检查显示生命、护盾及伤害预估与内核一致。

## 执行状态

六条首通路径全部完成并通过玩法断言。通过五条连续完成路径加手机鹿独立复跑，组合覆盖三初始伙伴 × 两视口；不是一次不中断的全量运行。独立失败恢复、迁移及存储保护补测最终退出码为 0。

两次长任务曾被系统挂起/明显墙钟跳变打断；复跑保持原 30 秒等待上限，没有强制点击或放宽游戏断言。第二次超时捕获时，页面已为 `data-playing="false"` 且技能可操作；未复现永久锁死。最终应按各条已完成用例组合报告，不能称为一次不中断的全量运行。

| 初始伙伴 | 桌面三场行动数 | 手机三场行动数 |
| --- | --- | --- |
| 九尾狐 | 10 / 16 / 12 | 10 / 16 / 12 |
| 旋龟 | 12 / 13 / 12 | 12 / 13 / 12 |
| 鹿蜀 | 12 / 15 / 11 | 12 / 15 / 11 |

每条路线均收齐六兽、确认三种进化、完成尾声并重打归泉守望。行动数按山隘、苇泽、泉眼顺序，包含换兽，非真人用时。使用狐、龟、鹿阵容，随敌属性切换，再选择冷却外的最高威力伤害技能。

发现并修复了进化与尾声浅色按钮文字对比度不足，以及地图 CSS 背景引用不存在的 `battle-bg.png` 导致 404；修正为实际的 `battlefield.png` 后，桌面/手机地图独立 HTTP/控制台检查通过，无 4xx/5xx 或浏览器错误。最终桌面/手机地图、战斗、进化、尾声截图经查看，横向无溢出、素材完整、信息可读。进化预览明确检查三个 `*-evolved.png` 地址，不仅检查图片加载成功。

### 独立补测结果

- 真实合法换兽 13 次后落败；经验、收集和道具不变。结果页返回地图、进入队伍、重新挑战恢复满血，并再次胜利。
- 导出/导入精确往返、取消新旅程、备份恢复、错误 JSON 和未知版本导入拒绝均通过。
- v1 队伍与经验迁移到 v2；首次写入保存原文，刷新保留备份，`导出 v1 原始存档` 返回逐字相同内容。
- 损坏/未来存档不被自动覆盖，可导出原文；显式新旅程保留原始备份；禁用浏览器存储仍能进入旅程。
- 最终失败/重试 + 迁移/保护用例 `errors: []`，独立地图资源检查 `errors: []`。早期 404 是实际问题，已修复并针对复验，不将修复前运行描述为控制台干净。

本机审阅截图与已完成真实流程存档位于 `/private/tmp/shanhai-chapter-final/`。截图包含 `map`、`evolution`、`battle`、`ending` 的 `1440`/`390` 版本及手机失败页。执行日志为 `/private/tmp/shanhai-chapter-final.log`（五条完成后被挂起打断）、`/private/tmp/shanhai-chapter-deer.log`（手机鹿完成、暴露已修复的 404）、`/private/tmp/shanhai-chapter-focused.log`（补测成功）及 `/private/tmp/shanhai-map-check.log`（最终资源复验成功）。这些是本机临时验收产物，不是公共部署地址。

## 限制

手机为浏览器视口模拟，非真机测试。自动操作不代表真人通关时长或难度；20–30 分钟仍是设计目标。未验证公共部署、真人试听或长期存储可靠性。

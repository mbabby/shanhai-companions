## 已确认

网页版；原创山海经及中国神话题材；异兽收集养成和回合制对战；幼体可爱、成长后威严；GitHub 开源开发与持续进展同步。

## 提案：玩家与第一章

工作名《山海同行》。玩家是记录异兽习性、与异兽结伴的“录灵人”。第一章位于原创区域“青岚谷”：水源异常迫使异兽迁移，玩家探索林地、溪流与山隘，寻找原因。

推荐以探索与策略对战结合起步。替代方案是纯对战原型或陪伴养成；最终方向仍需确认。

## 首批异兽候选

下列昵称、属性、定位与成长形态均为原创改编提案，非古籍原有设定。

| 原型 / 昵称 | 造型原则 | 战斗定位 |
| --- | --- | --- |
| 九尾狐 / 小绒 | 幼体九条短绒尾，成长后尾部舒展 | 火，输出与灼伤 |
| 旋龟 / 砚砚 | 鸟首龟身长尾，成长后突出甲壳与体量 | 水，防御与反击 |
| 鹿蜀 / 阿蜀 | 马形、白首、虎纹、赤尾，成长后修长灵动 | 木，回复与支援 |
| 狸力 / 团掘 | 豚形与掘土足爪，成长后肩背厚实 | 土，护盾与破防 |
| 狌狌 / 白耳 | 白耳幼猿，保持灵活体态 | 木，速度与干扰 |
| 鯥 / 游角 | 牛形、翼、蛇尾的组合 | 水，进攻与减速 |

初始伙伴拟从九尾狐、旋龟、鹿蜀中三选一；另外两种仍可在后续探索中获得。首个完整试玩建议仅制作三种成长形态，其余成长留待后续。

## 战斗提案

- 每队 3 只，单只上场；玩家和敌方每回合各选择一次行动。
- 普通攻击、特色技能、战术技能，每只先设 3 个技能。
- 行动先按优先级，再按速度结算；同速、倒下补位、冷却和状态结算细则尚待规格化。
- 主动换兽占用一回合行动，先于普通技能，新上场异兽承受敌方攻击。
- 普通攻击始终可用，强技能使用短冷却。
- 首批状态限定灼伤、减速、护盾。
- 简化克制环：木克土、土克水、水克火、火克木。不是传统五行的完整解释。
- 克制倍率拟为 1.5，被克制为 0.75，其余正常；均需验证与平衡。

目标：至少两种阵容能过关，换兽及战术技能确实有用，玩家能理解失败原因并尝试调整。

## 捕捉提案

推荐“习性互动 + 战斗考验 + 结契”：寻找踪迹、完成习性互动、战斗达成条件后用契印获得伙伴。首版拟在满足明确条件后保证成功，暂不加入随机捕捉。

普通胜利获取培养材料，结契获得伙伴；教学首次免费。条件、失败处理、重复获取及成本尚待确认。

## 完整试玩流程提案

选伙伴与教学战 → 林地第一次结契 → 溪流补齐队伍 → 山隘学习防守与破防 → 初始伙伴成长 → 挑战成年旋龟首领。

完整试玩目标约 20–30 分钟，结束后可以重打首领、收集剩余异兽。时长属于目标而非实测。

## 网页与数据方案

2D 地点探索与独立战斗场景；电脑、手机共用规则，触屏可完成主要操作。战斗计算与画面解耦，异兽和技能用配置定义。技术栈尚未选择。

第一版计划使用浏览器本地存档，并提供导出备份；清理站点数据会影响本地进度。需要定义存档版本、加载校验及异常恢复。战斗、捕捉、成长完成后保存。

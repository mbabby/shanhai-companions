# 山海同行 · Shanhai Companions

一款正在共同设计与开发的开源网页游戏：从《山海经》和中国神话中汲取灵感，以原创异兽形象呈现探索、收集、培养与回合制对战。

> **当前阶段：设计草案。尚无游戏代码、可玩演示或已部署站点。**

## 已确定的方向

- 平台：网页版，面向电脑与手机浏览器。
- 玩法方向：异兽收集、养成、组队与回合制战斗。
- 题材：《山海经》与中国神话；角色造型、故事和美术采用原创表达。
- 视觉：幼体亲近可爱，成长后表现不同类型的神兽威严。
- 开发方式：GitHub 公开开发，有可验证进展时同步代码、文档和任务状态。

“山海同行”为工作名。具体玩法、首批异兽、属性和数值仍待设计确认。

# 山海同行 · Shanhai Companions

一款正在共同设计与开发的开源网页游戏：从《山海经》和中国神话中汲取灵感，以原创异兽形象呈现探索、收集、培养与回合制对战。

> **当前阶段：首个可玩原型 v0.1。选伙伴、习性结契、三兽配队、五行战斗与首领结算已接入；尚未部署公共站点。**

## 本地试玩

需要 Node.js 22 或更新版本，无运行时第三方依赖。

```sh
npm ci
npm run dev
```

打开 http://127.0.0.1:4173 。选择初始伙伴，在两个地点观察习性并结契，组成三兽队伍后挑战守关队伍。普通攻击随时可用，特色技能有冷却；主动换兽会消耗本回合行动，倒下自动补位。失败后可重试，也可以重新开始旅程。

首版不保存进度，刷新页面会重开。数值、角色属性和互动答案均为试玩假设；尚无升级、进化、音效、账号、付费或多人功能。

```sh
npm test          # 战斗规则与边界测试
npm run build    # 生成 dist/ 静态站点
npm run preview  # 本地预览 dist/
```

预览默认占用同一端口，运行前先停止 dev；也可用 `PORT=4174 npm run preview`。构建输出可由普通静态服务器托管。

可选浏览器测试（保持 dev 服务运行，在另一个终端执行）：

```sh
npm install --no-save --package-lock=false playwright
npx playwright install chromium
npm run test:browser
```

也可通过 `CHROME_PATH` 使用本机 Chrome，通过 `PLAYWRIGHT_MODULE_PATH` 指定已安装的 Playwright 入口；`BASE_URL` 和 `SCREENSHOT_DIR` 可覆盖测试地址与截图目录。CI 当前运行规则测试与构建，浏览器测试需单独执行。

## 已确定的方向

- 平台：网页版，面向电脑与手机浏览器。
- 玩法方向：短冒险串起异兽捕捉、配队和成长，回合制战斗是核心。
- 属性：金、木、水、火、土，采用传统相克关系。
- 捕捉方向：通过习性互动与异兽结契。
- 题材：《山海经》与中国神话；角色造型、故事和美术采用原创表达。
- 视觉：幼体亲近可爱，成长后表现不同类型的神兽威严。
- 开发方式：GitHub 公开开发，有可验证进展时同步代码、文档和任务状态。

“山海同行”为工作名。首批异兽、结契细节和战斗数值仍待设计确认。

# 山海同行 · Shanhai Companions

一款正在共同设计与开发的开源网页游戏：从《山海经》和中国神话中汲取灵感，以原创异兽形象呈现探索、收集、培养与回合制对战。

> **当前交付：青岚谷第一章 v0.4.2。探索、结契、配队与三场关键战斗串成一段完整冒险；验证状态见 [进展记录](docs/progress.md)。尚未部署公共站点。**

采用已确认的东方幻想绘本方向，幼体与进化形态使用原创生成的手绘立绘。战斗通过静态立绘、位移、元素飞弹和受击效果演出，尚非逐帧角色动画。生命、护盾、成长数值与伤害预估均读取实际规则。

## 本地试玩

需要 Node.js 22 或更新版本，无运行时第三方依赖。

```sh
npm ci
npm run dev
```

打开 http://127.0.0.1:4173 。从九尾狐、旋龟或鹿蜀中选择初始伙伴，进入青岚谷寻找水源异常的原因。

- 八个节点包含谷口、林地、溪流、山隘、沼泽、灵祠、泉源与可选支线。地图显示下一目标与未解锁原因。
- 观察习性、处理环境后与异兽结契；六种异兽都能收集，最多三只出战，其余留在后备。战斗外可调整队伍和领队。
- 三场关键战斗分别有护甲、速度与周期增伤规则；出招前查看地形提示与五行克制。
- 灵祠共鸣解锁初始三种异兽的进化，各有新的立绘和技能效果。完成泉源战后阅读结局，继续补齐图鉴或重新挑战。

20–30 分钟为第一章体验目标，尚未完成真人时长测量。章节没有账号、云存档、多人对战或付费系统。

## 成长、战斗与存档

每队三只不同异兽，单只出场。普攻无冷却，特色和战术技能有冷却；主动换兽消耗一次行动，倒下自动补位。点击技能后立即显示操作与演出进度，可点「立即结算」跳过等待；演出异常/超时会统一恢复。支持演出 ×1/×2、减少动态和独立音效/氛围开关；声音默认关闭，需点击解锁。

经验上限 90、等级上限 3。每场章节战斗首次胜利给出战队伍各 30 经验，重打和失败不重复发放。灵祠共鸣让已收集的初始三种异兽达到进化所需经验，之后仍须主动选择进化；后续收集的初始种也可回灵祠共鸣。进化在下一次战斗生效。

阶段变化与完整回合后自动保存。演出途中刷新会回到该回合开始前，避免保存半次伤害。页面下方的「旅程存档与声音设置」支持 JSON 导入导出、原文导出、备份恢复和新旅程确认。

v0.3 的有效旧存档可迁入第一章，保留已获得伙伴、经验与设置；旧版单场试炼不视为完成本章关卡。迁移前的原始存档可单独导出。损坏或未来版本不自动覆盖。存档仅属于当前站点和浏览器，清理网站数据前请导出；备份不能替代离线导出或云同步。

## 验证与构建

```sh
npm test
npm run build
npm run preview
```

构建生成 `dist/`，可由普通静态服务器托管。预览默认占用同一端口，运行前先停止 dev；也可使用 `PORT=4174 npm run preview`。

当前第一章浏览器验收（保持 dev 服务运行，在另一终端执行）：

```sh
npm install --no-save --package-lock=false playwright
npx playwright install chromium
npm run test:chapter
```

也可通过 `CHROME_PATH` 使用本机 Chrome，通过 `PLAYWRIGHT_MODULE_PATH` 指定已安装的 Playwright 入口；`BASE_URL` 和 `SCREENSHOT_DIR` 可覆盖测试地址与截图目录。`test:browser` 与 `test:chapter` 均运行当前第一章验收。`test:legacy:browser`、`test:legacy:presentation`、`test:legacy:save` 保留为 v0.3 界面历史脚本，流程选择器不适用于第一章。CI 运行规则测试与静态构建，浏览器验收单独执行。

## 已确定的方向

- 平台：网页版，面向电脑与手机浏览器。
- 玩法方向：短冒险串起异兽捕捉、配队和成长，回合制战斗是核心。
- 属性：金、木、水、火、土，采用传统相克关系。
- 捕捉方向：通过习性互动与异兽结契。
- 题材：《山海经》与中国神话；角色造型、故事和美术采用原创表达。
- 视觉：幼体亲近可爱，成长后表现不同类型的神兽威严。
- 开发方式：GitHub 公开开发，有可验证进展时同步代码、文档和任务状态。

“山海同行”为工作名。当前原型规则可随实际试玩反馈调整。
